
# Multivariate EDA and Data Visualization Demos


## Overview

This repository contains a series of projects and demonstrations focused on exploratory data analysis (EDA) and data visualization techniques. The objective is to provide practical examples of analyzing and visualizing data using Python, showcasing tasks like identifying trends, relationships, and actionable insights.
## Key Features

- Multivariate EDA on Cereal Dataset:

  Exploration of nutritional data of cereals.

  Identification of top manufacturers based on customer ratings.

  Replacement of manufacturer codes with full names.

  Scatter plots for analyzing protein and calorie relationships.

  Heatmaps for correlation and covariance between nutrients.

- Scatter Plot Visualization Demo:

  Analysis of the relationship between total bill and tips using scatter plots.

  Insights into gender and smoking status effects on tipping behavior.

  Advanced visualization features like hue and layout adjustments.

- Cross Tabulation Demo:

  Analysis of a bank marketing dataset to explore term deposit subscriptions.

  Demonstration of cross-tabulation for bivariate categorical data.

## Technology Used

- Programming Language: Python

- Libraries:

  pandas for data manipulation and analysis.

  numpy for numerical operations.

  matplotlib and seaborn for data visualization.

  scipy for statistical analysis.
